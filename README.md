# Digital Realm - Event & Asset Management

A Next.js 16 full-stack application for managing gaming events and digital assets.

## Setup

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Features

- ✅ Next.js 16 + TypeScript
- ✅ Tailwind CSS 4
- ✅ Redux Toolkit with RTK Query
- ✅ Lucide React Icons
- ✅ Fixed background hero section
- ✅ Black navbar with gaming theme
- ✅ Responsive design
